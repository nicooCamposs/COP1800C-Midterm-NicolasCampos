This project implements the StudyRoom Java application to protect object state, enforce class invariants, manage private fields, handle constructor input validations, and support overloaded reservation methods[cite: 5, 6].

- StudyRoom.java: Containins private fields, validated constructors with exception handling, constructor chaining, getters, and safe state-transition methods for reserving and canceling seats[cite: 5, 6].

- StudyRoomDemo.java: Demonstration class executing sequential trace tests, constructor exception handling, default capacity checks, full cancellations, and object reference comparisons between aliases and independent objects[cite: 5].
