Java application that manages study room reservations, protects internal data, and controls capacity limits.

Project files:
StudyRoom.java: Contains room structure, data validations, and methods to reserve or cancel spaces.
StudyRoomDemo.java: Test class that executes operations step by step and checks program operation.

Compilation and execution:
javac StudyRoom.java StudyRoomDemo.java
java StudyRoomDemo
